    v25.0 - ArchLinux Installation¶

    And here we go again.

    Yes, that many incomplete, lost interest and failed attempts.

    And this what's new we are using the Shiny new AI ChatGPT5 Plus.

    Frankly this was a great help in compiling info needed and getting the things working.

    Also, new this time is the USB Installation.

    Weird ! nah.

    The only thing chained to a PC is Windows.

    With Linux you have USB SSDs the bright multi-architecture capable installation target. Install it once and run in anywhere.

    It's kind of dream come true, Linux unchained.

    AI is good but it some times misses the point and hallucinates. Good thing its attempt number 25 for doing ArchLinux.

    But actually this document is being revised every now and then. As in the process of installing ArchLinux the learning on the way is kind of how we get therapy.

    Install Media for Arch Linux¶

    This time we used the August'2025 Media:

    https://geo.mirror.pkgbuild.com/iso/2025.08.01/

    Setting Up to help us get SSH into the ArchLinux Installation¶

    Also new this time is that we used another computer to enter the instructions.

    Setting up password for Root user:

    passwd

    That's the first thing you do.

    Now getting Internet with WiFi is already document in V21 steps.

    And while we are at it let's check out ArchLinux:

    ping -c 2 archlinux.org

    Next, the Time Zone setting already documented in V21 steps.

    Thats all we need.

    Well not quite, we need the IP address so that we can ssh as root into this ArchLinux Install target.

    ip -c a

    Note down the I/P address shown for the Wireless.

    If this is too much to understand then lets do a iwdctl way too:

    $ iwdctl
[iwd]# station wlan0 show

    This should display the full information about the current connection.

    All, green - you are ready to Arch.

    Partitioning for ArchLinux Install on USB SSD¶

    Well this might be the hardest part of all.

    We have attempted multiple installs just to establish good repeatability.

    Partition Layout 1 for ArchLinux with LUKS and Single Root on USB SSD¶

    Partition Type Size
    biosgrub Legacy BIOS MBR 2MiB
    ESP ESP UEFI Standard 1024MiB
    root Linux FileSystem 300GiB

    Simple straight forward and easy to understand.

    This time we are using the disk-id method only.

    First we find our disks 

    ls -l1 /dev/disk/by-id/usb*
lrwxrwxrwx 1 root root  9 Sep 23 06:41 /dev/disk/by-id/usb-Sabrent_SSD_12320240124000A-0:0 -> ../../sdb
lrwxrwxrwx 1 root root 10 Sep 23 06:41 /dev/disk/by-id/usb-Sabrent_SSD_12320240124000A-0:0-part1 -> ../../sdb1
lrwxrwxrwx 1 root root 10 Sep 23 06:41 /dev/disk/by-id/usb-Sabrent_SSD_12320240124000A-0:0-part2 -> ../../sdb2
lrwxrwxrwx 1 root root 10 Sep 23 06:41 /dev/disk/by-id/usb-Sabrent_SSD_12320240124000A-0:0-part3 -> ../../sdb3
lrwxrwxrwx 1 root root  9 Sep 23 06:41 /dev/disk/by-id/usb-SABRENT_SSHD_AAAABBBBCCCC0003-0:0 -> ../../sdc
...

    Next lets begin by entering the partitions visually using cfdisk

    export YourSSD="<your SSD name>"
cfdisk /dev/disk/by-id/$YourSSD-0:0

    Once you have written the image or corrupted your other disks.

    Na, that ain't going to happen. You are using the superior disk-id method.

    Let's begin, formatting fun.

    First, the ESP of course:

    mkfs.fat -F32 -n ESP_USB /dev/disk/by-id/$YourSSD-0:0-part2

    Setup the LUKS:

    cryptsetup luksFormat /dev/disk/by-id/$YourSSD-0:0-part3

    cryptsetup open /dev/disk/by-id/$YourSSD-0:0-part3 cryptroot

    mkfs.ext4 -L archroot /dev/mapper/cryptroot

    Now for Mounting all things:

    mount /dev/mapper/cryptroot /mnt
mkdir -p /mnt/boot
mount /dev/disk/by-id/$YourSSD-0:0-part2 /mnt/boot

    pacstrap you ArchLinux Install on USB SSD¶

    pacstrap -K /mnt \
  base base-devel linux linux-lts linux-firmware sof-firmware \
  vim nano networkmanager nano-syntax-highlighting git bash-completion \
  iwd wpa_supplicant grub efibootmgr os-prober reflector zram-generator \
  intel-ucode amd-ucode

    We install all the basics and note the two ucode as we have multi-Architecture to support. Also we are using zram for swap.

    Let's now generate the fstab

    genfstab -U /mnt >> /mnt/etc/fstab

    Finally enter the Installation:

    arch-chroot /mnt

    Editing the mkinitcpio for Portable LUKS and possibly hibernate in arch-chroot¶

    Edit the /etc/mkinitcpio.conf file, scroll to the like where you see HOOKS=(...

    Default it should look like this:

    # /etc/mkinitcpio.conf
HOOKS=(base udev autodetect microcode modconf kms keyboard keymap consolefont block filesystems fsck)

    Update it to:

    # /etc/mkinitcpio.conf
HOOKS=(base udev microcode modconf kms keyboard keymap consolefont block encrypt filesystems fsck)

    The important thing here is:

    • Removing autodetect to allow the kernel to load the required micro-code automatically.
    • Adding encrypt after block to make sure we have LUKS.

    Now let us regenerate the mkinitcpio :

    mkinitcpio -P

    We would need to do this again after the edits to grub

    Fixing the Kernel cmdline for LUKS root and possibly Resume target in arch-chroot¶

    Get the UUID of the Root Partition:

    blkid /dev/disk/by-id/$YourSSD-0:0-part3

    Keep the UUID='... part we need to add this to grub configuration.

    Edit the file /etc/default/grub and change the GRUB_CMDLINE_LINUX= to:

    GRUB_CMDLINE_LINUX="cryptdevice=UUID=<UUID-of-$YourSSD-0:0-part3>:cryptroot:allow-discards root=/dev/mapper/cryptroot"

    Yes this is very long one.

    Also edit this part:

    # Uncomment to enable booting from LUKS encrypted devices
GRUB_ENABLE_CRYPTODISK=y

    This is needed to help us with LUKS mount.

    While at it lets color our GRUB menu a bit:

    # Uncomment and set to the desired menu colors.  Used by normal and wallpaper
# modes only.  Entries specified as foreground/background.
GRUB_COLOR_NORMAL="light-blue/black"
GRUB_COLOR_HIGHLIGHT="light-cyan/blue"

    And if you need to have the detection of Windows on your local disk or some other Linux Installation that you may have:

    # Probing for other operating systems is disabled for security reasons. Read
# documentation on GRUB_DISABLE_OS_PROBER, if still want to enable this
# functionality install os-prober and uncomment to detect and include other
# operating systems.
GRUB_DISABLE_OS_PROBER=false

    Now save this file. We are ready to do the next installation of grub.

    Setting Up Discard friendly permission for Root fstab in arch-chroot¶

UUID=<your-root-UUID> / ext4 rw,noatime,errors=remount-ro 0 1

    Save the file. It would automatically be done once booting into the new system.

    zram Swap definition in arch-chroot¶

    Create the ZRAM config:

    cat >/etc/systemd/zram-generator.conf <<'EOF'
[zram0]
# Pick a size policy. "ram / 2" is a safe starting point for 8–16 GB RAM.
# Example effective sizes:
#  - 8 GB RAM  -> 4G zram
#  - 16 GB RAM -> 4G zram
zram-size = min(ram / 2, 4096)

# Compression: zstd = better ratio, lz4 = lower CPU
compression-algorithm = zstd

# Prefer ZRAM over any future real swap
swap-priority = 100
EOF

    Ram Size

    Note that here we are picking ram / 2 you can also set a fixed value or set it as ram / 3 if needed. Also there is a min limit of 4096MiB.

    Compression

    Here we have set zstd but if you are not using SWAP that much then feel free to set this to lz4.

    Now let us enable the Service:

    # systemctl enable dev-zram0.swap

    This is not needed as the zram-generator will automatically activate the device as boot.

    The zram-generator creates a systemd-managed device /dev/zram0 and a dev-zram0.swap unit from the config file /etc/systemd/zram-generator.conf.

    Finally for Optimizing the ZRAM operation as per the Arch Wiki:

    cat >/etc/sysctl.d/99-zram.conf <<'EOF'
vm.swappiness = 180
vm.watermark_boost_factor = 0
vm.watermark_scale_factor = 125
vm.page-cluster = 0
vm.vfs_cache_pressure = 100
EOF

    Creating the User and adding Rights in arch-chroot¶

    First let's set the User Name of our choice:

    export YourUSER="<Your-USER-Name-Here>"

    This would make writing command whole lot easier.

    Now, we create the user with all the necessary permissions:

    useradd -m -s /bin/bash \
        -G wheel,audio,video,lp,scanner,storage,uucp,lock,power,rfkill \
        $YourUSER

    Then, set the password for the created user:

    passwd $YourUSER

    Next we need to add the wheel permission:

    cat >/etc/sudoers.d/10-wheel <<'EOF'
%wheel ALL=(ALL:ALL) ALL
EOF

    If you wish to check the file:

    visudo -cf /etc/sudoers.d/10-wheel   # validate syntax

    Finally set the Permissions on the file:

    chmod 0440 /etc/sudoers.d/10-wheel

    Let's create the XDG Directories for your User:

    runuser -l $YourUSER -c 'xdg-user-dirs-update'

    Now we Lock out the ROOT User for security:

    passwd -l root

    Also fix the SSHD configuration to Block ROOT login:

    sed -i 's/^#\?PermitRootLogin .*/PermitRootLogin no/' /etc/ssh/sshd_config

    May be enable the SSH service so that even after we reboot we have this convenient access.

    systemctl enable sshd

    Disable Bluetooth at boot and toggle using Blueman in arch-chroot¶

    # BlueZ: don't auto-enable adapters
printf "[Policy]\nAutoEnable=false\n" | tee /etc/bluetooth/main.conf

    Block auto Enable of Bluetooth using a Service:

    # rfkill soft-block at boot
tee /etc/systemd/system/rfkill-block-bluetooth.service >/dev/null <<'EOF'
[Unit]
Description=RFKill soft-block Bluetooth at boot
DefaultDependencies=no
After=local-fs.target
Before=bluetooth.service graphical.target multi-user.target
[Service]
Type=oneshot
ExecStart=/usr/bin/rfkill block bluetooth
[Install]
WantedBy=multi-user.target
EOF

# Enable the Services
systemctl daemon-reload
systemctl enable rfkill-block-bluetooth.service
systemctl enable bluetooth.service

    Exiting arch-chroot environment¶

    !WARNING! DO NOT directly Exit from arch-chroot

    Be cautious we need to do it in a step by step manner:

    # (optional) flush dirty buffers
sync

# (optional) if you mounted extra drives or opened LUKS volumes, close them first:
# 1) turn off swap file (safe, optional)
swapoff /swapfile

# Exit from the chroot
exit

    Finally unmount LUKS volume and other partitions Outside the arch-chroot:

    umount -R /mnt/boot
umount -R /mnt

    # Close the Encrypted volume
cryptsetup luksClose cryptroot

    Now we can reboot:

    systemctl reboot

    Securing the Machine¶

    Firewall Setting in UFW¶

    # Firewall Rules
sudo ufw limit 22/tcp comment "SSH"  # Remote session
sudo ufw allow 5353 comment "avahi" # avahi Discovery port
sudo ufw deny to 224.0.0.1 comment "block multicast packets" # Multi-cast Disable
sudo ufw default deny incoming
sudo ufw default allow outgoing
sudo ufw enable

    Finally we need to make sure it loads every time the system is started:

    sudo systemctl enable --now ufw

    Optional SSH Server secure if needed¶

    First is the SSH that we need to update after adding our Public Key:

    sudo sed -ri 's/^\s*#?\s*PasswordAuthentication\s+.*/PasswordAuthentication no/' /etc/ssh/sshd_config
sudo sed -ri 's/^\s*#?\s*PubkeyAuthentication\s+.*/PubkeyAuthentication yes/' /etc/ssh/sshd_config

    This would enable the PubkeyAuthentication yes and make PasswordAuthentication no

    Finally we need to Reload daemon:

    sudo systemctl reload sshd
